# Git 기초: 3대 작업 영역

## 작업 영역의 이해
1. **Working Tree**: 현재 개발자가 직접 편집하고 있는 로컬 디렉터리 상태입니다.
2. **Staging Area (Index)**: 다음 커밋에 포함시킬 변경사항을 선별하여 준비하는 영역입니다.
3. **Repository (Commit)**: 영구적으로 저장된 프로젝트의 스냅샷 이력입니다.

## 변경 추적 실습 예시 (피드백 반영)
- `git diff`: 작업 디렉터리와 스테이징 영역 간의 차이 비교
- `git diff --cached`: 스테이징 영역과 최신 커밋 간의 차이 비교
