# 충돌 1(AB) 발생 및 해결 기록

## 1. 개요 및 참여자
- 대상 파일: `src/practice/review-request.md`
- 분기 기준 커밋 SHA: `26a8ef5e148bd066e890e57328f368ecd5539e31`
- 선병합자: 김상교 (`feature/a-practice`)
- 충돌해결자: 장양환 (`feature/b-practice`)

## 2. 충돌 원인
동일 파일의 동일한 위치(`리뷰 요청: PR 링크를 공유한다.`)에 대해 김상교는 '변경 이유', 장양환은 '검증 결과'를 추가하여 Git 자동 병합 불가(동일 hunk 비자명 충돌) 발생.

## 3. 실제 발생한 충돌 마커 원문
```text
# 리뷰 요청 실습

<<<<<<< HEAD
리뷰 요청: PR 링크와 검증 결과를 공유한다.
=======
리뷰 요청: PR 링크와 변경 이유를 공유한다.
>>>>>>> main

```

## 4. 해결 절차 및 의사결정 이유
- 충돌 마커(`<<<<<<<`, `=======`, `>>>>>>>`)를 확인한 뒤, 양측의 변경 의도가 상충되지 않고 상호 보완적임을 파악함.
- 한쪽을 삭제하지 않고 두 의도를 모두 보존하여 `리뷰 요청: PR 링크, 변경 이유와 검증 결과를 공유한다.`로 문맥을 통합 해결함.
