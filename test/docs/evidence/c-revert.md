# C 조은익: revert 실습 기록

- 수행자: 조은익
- 대상 브랜치: `feature/c-practice`
- 실습 도구: `git revert`

## 2. 상황 및 재현 조건
- 원격 저장소에 이미 푸시된 공유 커밋을 취소해야 하는 상황을 가정하여 별도 실습 파일 생성.
- 원본 커밋 SHA: `20b886de1fa4333afabb20a5cfb3fdeaec158c65`

## 3. 실행 명령 및 결과
- 실행 명령: `git revert --no-edit 20b886de1fa4333afabb20a5cfb3fdeaec158c65`
- 역커밋(Revert 커밋) SHA: `c77b7e99e99e98ffcf5e79e5d5380aaa28fd5707`
- 결과: 이전 커밋 이력을 삭제(reset)하지 않고 취소하는 새로운 커밋을 추가하여 파일 상태를 안전하게 원복함.
- *참고: 본 실습은 로컬 환경에서 revert 동작 검증을 완료하였으며, 실제 원격 푸시 및 공유 이력 보존 검증은 팀 GitHub 저장소 환경에서 수행함.*

## 4. 선택 이유 및 주의점
- 원격에 이미 푸시된 커밋을 reset으로 되돌리고 force push하면 다른 동료들의 로컬 이력이 깨지는 치명적인 문제가 발생함.
- 협업 중 공유된 커밋 취소에는 항상 revert를 사용하여 이력을 투명하게 보존해야 함.
