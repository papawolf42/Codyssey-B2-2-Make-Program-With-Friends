# 충돌 2(CD) 발생 및 해결 기록

## 1. 개요 및 참여자
- 대상 파일: `src/practice/sync-timing.md`
- 분기 기준 커밋 SHA: `cad75de0d1b9f43fa37402e81933a8e714b7d195`
- 선병합자: 조은익 (`feature/c-practice`)
- 충돌해결자: 김건우 (`feature/d-practice`)

## 2. 충돌 원인
동일 파일 동일 위치(`동기화: 원격 변경을 확인한다.`)에 대해 조은익은 '작업 시작 전', 김건우는 'PR 병합 전'으로 수정하여 동일 hunk 비자명 충돌 발생.

## 3. 실제 발생한 충돌 마커 원문
```text
# 동기화 시점 실습

<<<<<<< HEAD
동기화: PR 병합 전에 원격 변경을 확인한다.
=======
동기화: 작업 시작 전에 원격 변경을 확인한다.
>>>>>>> main

```

## 4. 해결 절차 및 의사결정 이유
- 작업 시작 전 최신 변경 확인과 PR 병합 직전 최종 동기화는 둘 다 필수적인 협업 수칙임.
- 두 조건을 모두 포함하여 `동기화: 작업 시작 전과 PR 병합 전에 원격 변경을 확인한다.`로 통합 해결함.
