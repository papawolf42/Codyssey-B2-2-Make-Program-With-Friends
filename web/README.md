# 같이, Git — 첫 협업 이해도 확인

개발을 막 시작한 사람이 B2-2의 협업 흐름을 이해했는지 연습하는 웹입니다. [쉬운 설명서](../docs/0018_b2-2-first-week-guide.md)를 읽고, 상황 문제를 푼 다음 자신의 말로 설명해 보세요.

## 실행하기

**[index.html](index.html)을 다운로드한 뒤 더블클릭하면 됩니다.** 서버 실행, Node.js 설치, 인터넷 연결이 필요 없습니다. 저장소를 이미 내려받았다면 `web/index.html`을 브라우저로 여세요.

화면 디자인과 문제·해설·동작 코드가 HTML 한 파일에 모두 들어 있습니다. 이 파일만 다른 곳으로 복사해도 학습 기능은 동작합니다. 원문 문서 링크까지 사용하려면 저장소의 `docs/`와 `evalutation.md`도 원래 위치에 두세요. Markdown 원문은 브라우저에 따라 텍스트로 열리거나 다운로드됩니다.

## 이렇게 사용하세요

1. **개념부터 살펴보기:** commit, push, PR, merge를 쉬운 말로 구별합니다.
2. **이해도 확인:** 필수 상황 문제 22개를 풀고, 선택한 답의 이유와 오답 설명을 확인합니다. 틀린 문제나 특정 주제만 다시 풀 수 있습니다.
3. **내 말로 설명:** 필수 질문 13개에 직접 답한 뒤 핵심 내용·예시와 비교합니다. “설명할 수 있어요”는 본인이 표시하는 상태이며 자동 채점이 아닙니다.
4. **제출 자료 확인:** 팀의 실제 자료를 열어 보고 8개 항목의 근거를 적습니다. 메모를 써야 확인 표시를 할 수 있으며, 웹이 링크의 내용이나 GitHub 권한을 검사하지는 않습니다.
5. **나의 학습 기록:** 현재 정답과 첫 시도 정답을 나눠 확인하고, 답변·근거를 Markdown 파일로 내려받습니다.

rebase는 선택 문제 1개와 설명 질문 1개로 따로 제공합니다. 필수 점수에는 포함하지 않습니다.

## 평가표와의 관계

[evalutation.md](../evalutation.md)의 필수 기준은 21개이며, 조건부 rebase 보너스까지 합치면 22개입니다. 웹의 **상황 문제 22개**는 이해를 돕기 위해 나눈 연습 문제 수이므로 평가 기준 수와 다릅니다.

| 평가표 | 웹에서 확인하는 방법 |
| --- | --- |
| 항목 1 · 산출물 8개 | 제출 자료 확인 8개 |
| 항목 2 · 협업 규칙 5개 | 내 말로 설명 5개 |
| 항목 3 · 선택의 이유 5개 | 내 말로 설명 5개 |
| 항목 4 · 상황 적용 3개 | 내 말로 설명 3개 |
| 항목 4 · rebase 보너스 1개 | 선택 설명 질문 1개 |

각 항목은 원문 또는 쉬운 설명서로 연결됩니다. 현재 `test/`의 충족 여부와 보완점은 [평가 대조 검토](../docs/0020_b2-2-evaluation-audit.md)에 정리했습니다. 이 웹의 결과는 공식 PASS/FAIL 판정이나 실제 팀 참여 증명이 아닙니다.

## 기록 저장

답변은 브라우저가 로컬 파일 저장을 허용하면 자동 저장됩니다. 서버로 전송하지 않습니다. 같은 브라우저에서 같은 위치의 HTML 파일을 다시 여세요. 파일을 옮기거나 이름을 바꾸거나 브라우저 데이터를 지우면 이전 기록이 보이지 않을 수 있습니다. 이전 서버 주소에서 저장한 기록도 별도이므로 필요한 기록은 기존 화면에서 내려받으세요. 내려받은 파일을 다시 불러오는 기능은 없습니다.

초기화 버튼을 누르면 확인창이 뜹니다. 확인하면 이 웹의 답변과 메모만 지워집니다. 저장 공간이 차거나 사용이 차단되면 화면에 저장 실패 안내가 표시됩니다.

## 소스를 수정하거나 검증할 때만

일반 사용자는 아래 명령을 실행할 필요가 없습니다. 개발자가 문제·스타일·동작을 수정했다면 Node.js 20 이상에서 `web` 폴더로 이동해 실행합니다. 외부 패키지 설치는 필요 없습니다.

```bash
npm run build
npm test
npm run check
```

`npm run build`는 수정한 소스를 HTML 한 파일에 다시 넣습니다. 생성된 `index.html`도 함께 커밋하세요. 자동 테스트 8개는 평가 기준 연결, 문제·원문 연결, 재도전 점수, 보너스 제외, 저장 데이터 검증·복원·실패 처리, 기록 내용, 독립 HTML의 소스 일치·실행 구문을 검사합니다.

2026-09-29 Chrome에서 PC·모바일 화면, 오답 재도전, 새로고침 복원, 직접 설명 입력, 근거 입력 후 확인, 기록 다운로드, 초기화 취소·완료, 본문 바로가기를 확인했습니다. 초기화 검증에는 직접 만든 임시 답변만 사용했습니다.

위 브라우저 검증은 서버 방식으로 실행했을 때의 결과입니다. 단일 HTML 전환 후 자동 테스트 8개는 통과했습니다. 자동화 브라우저의 로컬 파일 접근 정책 때문에 `file://`에서의 직접 실행은 확인하지 못했습니다.

## 파일 구성

- `index.html`: 더블클릭으로 실행하는 완성본. 실행에 필요한 코드가 모두 포함됨
- `index.template.html`, `style.css`: 완성본을 만들기 위한 화면 틀과 스타일
- `content.js`: 문제, 해설, 설명 질문, 제출 자료 기준
- `app.js`: 화면 전환과 사용자 입력 처리
- `logic.js`: 학습 기록 검증, 점수 계산, 기록 생성
- `build.mjs`: 소스를 단일 HTML로 합치는 개발용 도구
- `tests/`: 학습 기능과 독립 HTML 자동 테스트
