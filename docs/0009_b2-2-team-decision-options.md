## 1. 명세서 필수 선택 옵션 (3대 양자택일)

과제 명세서([`instruction.md`](../instruction.md))에서 명시적으로 팀에 선택권을 부여한 3가지 핵심 항목입니다.

### ① 저장소 형태 선택 (명세 74~76줄)
- [ ] **[옵션 A - 권장]**: **GitHub Organization 저장소 생성**
  - *장점*: 실무 기업 환경과 100% 동일, 팀원 전원 동등한 관리자/멤버 권한, 프로필 Org 뱃지 부여
  - *통과팀 통계*: 선배 통과팀의 **70%**가 선택
- [ ] **[옵션 B - 대체]**: 팀원 1명의 개인 저장소 생성 후 Collaborator 초대
  - *단점*: 1인에게 저장소 소유권이 종속되어 팀 프로젝트 느낌이 퇴색됨

---

### ② "간단한 결과물" 유형 선택 (택 1, 명세 47~51줄)
- [ ] **[옵션 1 - 강력 추천]**: **팀원별 유틸 함수 모음 또는 미니 프로그램 (`src/` 폴더)**
  - *장점*: 코드 레벨에서 가장 자연스럽고 현실적인 충돌(Conflict)을 유발할 수 있어 피어 리뷰에서 가장 높은 점수 획득
  - *통과팀 통계*: 선배 통과팀의 **68.4%**가 선택
- [ ] **[옵션 2]**: **팀 소개 문서 (`README.md` + `team/` 폴더)**
  - 팀원별 자기소개 마크다운 문서 작성
- [ ] **[옵션 3]**: **학습 정리 노트 (팀원별 마크다운)**
  - Git 명령어 및 내부 동작 원리 정리 노트 작성

---

### ③ Git 히스토리 증빙 방식 선택 (택 1, 명세 45~46줄)
- [ ] **[방식 1 - 추천]**: **터미널 출력 텍스트 파일 저장 (`docs/git-history.txt`)**
  - `git log --oneline --graph --all > docs/git-history.txt` 명령어로 1초 만에 생성 가능
- [ ] **[방식 2]**: **터미널 또는 GitHub 커밋 그래프 캡처 스크린샷 이미지 첨부**
  - `docs/images/git-history.png` 파일로 저장

## 2. 팀 내부 세부 결정 사항 (4대 과제)

협업을 시작하기 전 팀 회의에서 확정해야 하는 실무 세부 규칙입니다.

### ④ 프로젝트 도메인(주제) 및 개발 언어
- **구현 언어**: **Python** (버전: 3.10 이상)
- **세부 주제 결정**:
  - [ ] **`TaskTracker CLI` (추천)**: 할 일 및 프로젝트 추적 콘솔 도구 (아키텍처 분리로 충돌 유도 최적)
  - [ ] **`Common Utils Lab`**: 문자열, 수학, 날짜 공통 유틸 함수 모음 (로직 부담 최저)
  - [ ] **`Mini Game CLI`**: 음식 이상형 월드컵 토너먼트 등 간단한 CLI 게임

---

### ⑤ 비자명 충돌(Non-trivial Conflict) 시나리오 결정 (1회 필수)
과제 필수 요건인 "비자명 충돌"의 연출 방식을 결정합니다.
- [ ] **[추천] 파일명 변경(`git mv`) vs 내용 수정(`Modify`) 충돌**
  - 예: 한 팀원이 모듈 리팩토링(`storage.py` ➔ `json_storage.py`)을 하는 동안, 다른 팀원이 `storage.py`에 인코딩 버그 수정을 반영하여 머지
- [ ] **파일 삭제(`git rm`) vs 내용 수정 충돌**
- [ ] **데이터 스키마 인접 라인 충돌** (동일 JSON/Dataclass 필드 동시 확장)

---

### ⑥ Git 4대 트러블슈팅 역할 배분 (4인 1도구)
팀원 전원이 최소 1개 이상 분담하여 실습하고 `docs/troubleshooting-log.md`에 기록합니다.

| 도구 | 담당 팀원 | 실무 상황 시나리오 | 결정 체크 |
|:---|:---:|:---|:---:|
| **`git commit --amend`** | **팀원 1** | 커밋 메시지 오타 수정 또는 누락 파일 보완 | [ ] |
| **`git reset --soft`** | **팀원 2** | 불필요한 임시 디버깅 파일 커밋 취소 후 재스테이징 | [ ] |
| **`git revert`** | **팀원 3** | 이미 원격 `main`에 머지된 결함 커밋을 히스토리 보존하며 취소 | [ ] |
| **`git stash` / `pop`** | **팀원 4** | 작업 중 긴급 브랜치 이동 요청에 따른 임시 보관 및 복원 | [ ] |
